## 🚀 Tech Stack
- **Framework:** Vite + React 19 + TypeScript
- **Styling:** Tailwind CSS v4 + Islamic Royal Emerald & Warm Gold color system
- **Icons:** Lucide React + Custom SVG Islamic Crescents
- **Typography:** Amiri (Arabic calligraphy), Playfair Display, Plus Jakarta Sans
- **Deployment:** Vercel / GitHub

## 🛠️ Local Development
```bash
# Install dependencies

# Start local development server
npm run dev

# Build for production
npm run build
```
